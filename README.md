# Refund - Projeto de Estudos

Pequeno projeto React + Vite criado para estudos e prática.

Stack
- React + TypeScript
- Vite
- TailwindCSS

Como rodar
1. Instale dependências:
   npm install

2. Rode em desenvolvimento:
   npm run dev

Estrutura principal
- src/
  - components/  # componentes reutilizáveis
  - pages/       # páginas do app
  - routes/      # definição de rotas
  - assets/      # imagens e ícones
  - utils/       # utilitários
- public/        # arquivos estáticos

Nota
- Este repositório é para fins de aprendizado.

Contribuição
